Chỉ cần nêu tên bài hoặc dán câu chuyện — app tự viết kịch bản, tạo hình, vẽ sơ đồ, dựng bảng số liệu, thu giọng đọc và ghép thành video.

🔑 1. Hồ Key Gemini (miễn phí)

Kiểm tra nhẹ không tốn quota sinh ảnh/giọng; key đạt = key hợp lệ và gọi được model.
Key chỉ lưu trong trình duyệt này (localStorage), app không gửi key đi nơi nào khác ngoài Google.
Chưa có key? Xem 3 bước tạo key MIỄN PHÍ
- Bước 1: Mở trang aistudio.google.com và đăng nhập bằng tài khoản Google.
- Bước 2: Bấm "Get API key" (khoá API) → "Create API key" (Tạo khoá API) → tạo trong dự án mới.
- Bước 3: Sao chép dãy ký tự bắt đầu bằng AIza... rồi dán vào ô phía trên (mỗi key 1 dòng) và bấm Lưu Hồ Key.
Gói miễn phí có hạn mức theo ngày cho TỪNG key — dán nhiều key là app tự chuyển key khi một key hết hạn mức.
