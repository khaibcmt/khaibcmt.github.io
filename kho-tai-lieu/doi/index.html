📦 QUY ĐỊNH NỘP BÀI (CHỐT LẠI TỐI 24/11 — ĐÍNH KÈM FILE TRONG CUỘC TRÒ CHUYỆN)

  • Đường nộp CHÍNH từ tối 24/11: làm xong sản phẩm → gom vào 1 file ZIP → đính kèm file ZIP đó ngay trong cuộc trò chuyện của bạn với thầy, kèm 1 dòng nhắn ghi rõ tên sản phẩm (ví dụ: "Em nộp 8 clip Tập 2 — Vòng 1 Ký Sự"). Vậy là xong — không cần tài khoản, không cần đăng nhập, không cần mở trang nào khác.
  • Vì sao đường này chạy được: thầy tải file bạn đính kèm về máy thầy → thư mục trên máy thầy tự đồng bộ lên Drive theo thời gian thực → Đạo diễn vào Drive lấy về nghiệm thu. Thầy và Đạo diễn đã kiểm chứng chạy thật tối 24/11.
  • Tên file ZIP theo mẫu TÊN_SẢN PHẨM_NGÀY.zip (ví dụ MUA_CLIP_TAP2_2411.zip); gom tất cả vào 1 file ZIP, không nộp file rời, không nộp link xem online.
  • Đạo diễn làm gì: lấy bài từ thư mục đồng bộ về, nghiệm thu trong ngày, đăng kết quả lên bảng này và đưa bản đạt lên kho GitHub.
  • Đường DỰ PHÒNG (chỉ khi đính kèm file trong cuộc trò chuyện bị lỗi hoặc file quá nặng không đính kèm được): đưa file lên litterbox.catbox.moe (chọn 7 days) lấy link → gửi link qua Cổng nộp bài. TUYỆT ĐỐI KHÔNG dùng Wormhole (dịch vụ đó giải mã file ngay trong trang, Đạo diễn không tải về tự động được) và không dùng SwissTransfer (bắt điền email người gửi).
  • Ngoại lệ — Kill: Kill xuất file trên máy thầy, thầy lưu vào thư mục đồng bộ là Đạo diễn tự vào lấy được — giữ nguyên cách đang làm, không đổi gì.
