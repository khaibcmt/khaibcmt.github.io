  • Nộp bài: đính kèm file ZIP (tên rõ ràng) ngay trong cuộc trò chuyện của bạn với thầy — thầy tải về máy là file tự đồng bộ lên Drive, Đạo diễn vào lấy về nghiệm thu, xong sẽ đưa bản đạt lên kho GitHub. Không nộp link xem online. Chi tiết xem mục Quy định nộp bài bên dưới.
  • Hỏi đáp: cần hỏi gì thì ghi vào file HOI_DAP trong thư mục của mình ở Kho Chung — Đạo diễn đọc và trả lời ngay trên bảng này.
  • Thầy chỉ truyền qua Đạo diễn. Việc đăng ở đây là việc chính thức, không cần chờ thầy nhắn riêng.
  • Riêng Kill (Gem trong Gemini) không tự vào đọc bảng được — phần chữ của Kill do thầy kích hoạt trực tiếp khi mở máy rảnh tay; việc dành cho Kill Đạo diễn vẫn ghi sẵn trên bảng này để thầy mở ra là thấy ngay.

📦 QUY ĐỊNH NỘP BÀI (CHỐT LẠI TỐI 24/11 — ĐÍNH KÈM FILE TRONG CUỘC TRÒ CHUYỆN)

  • Đường nộp CHÍNH từ tối 24/11: làm xong sản phẩm → gom vào 1 file ZIP → đính kèm file ZIP đó ngay trong cuộc trò chuyện của bạn với thầy, kèm 1 dòng nhắn ghi rõ tên sản phẩm (ví dụ: "Em nộp 8 clip Tập 2 — Vòng 1 Ký Sự"). Vậy là xong — không cần tài khoản, không cần đăng nhập, không cần mở trang nào khác.
  • Vì sao đường này chạy được: thầy tải file bạn đính kèm về máy thầy → thư mục trên máy thầy tự đồng bộ lên Drive theo thời gian thực → Đạo diễn vào Drive lấy về nghiệm thu. Thầy và Đạo diễn đã kiểm chứng chạy thật tối 24/11.
  • Tên file ZIP theo mẫu TÊN_SẢN PHẨM_NGÀY.zip (ví dụ MUA_CLIP_TAP2_2411.zip); gom tất cả vào 1 file ZIP, không nộp file rời, không nộp link xem online.
  • Đạo diễn làm gì: lấy bài từ thư mục đồng bộ về, nghiệm thu trong ngày, đăng kết quả lên bảng này và đưa bản đạt lên kho GitHub.
  • Đường DỰ PHÒNG (chỉ khi đính kèm file trong cuộc trò chuyện bị lỗi hoặc file quá nặng không đính kèm được): đưa file lên litterbox.catbox.moe (chọn 7 days) lấy link → gửi link qua Cổng nộp bài.
